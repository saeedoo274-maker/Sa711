# البوت الإداري الاحترافي — Discord

بوت إدارة سيرفرات ديسكورد، عربي بالكامل، مبني بهيكلية Modular ويعمل على عدد غير محدود من السيرفرات في نفس الوقت مع عزل كامل بين إعدادات كل سيرفر.

**65 أمر • 28 نظام • لوحة تحكم مركزية `/devpanel` • قاعدة بيانات حقيقية • محرك صلاحيات مركزي**

---

## 1) المتطلبات

| المتطلب | الإصدار |
|---|---|
| Node.js | 18 أو أحدث (يُفضّل 20+) |
| npm | 9 أو أحدث |
| أدوات البناء | مطلوبة لتثبيت `better-sqlite3` |

**أدوات البناء حسب النظام:**
- **Windows:** ثبّت [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) مع حزمة "Desktop development with C++"
- **Linux (Ubuntu/Debian):** `sudo apt install -y build-essential python3`
- **macOS:** `xcode-select --install`

> معظم الاستضافات الجاهزة (Railway, Render, VPS) تحتوي هذه الأدوات مسبقًا.

## 2) التثبيت

```bash
# 1. ثبّت المكتبات
npm install

# 2. أنشئ ملف الإعدادات
cp .env.example .env
```

ثم افتح `.env` وعبّي القيم:

```env
BOT_TOKEN=توكن_البوت_من_بورتال_ديسكورد
CLIENT_ID=آيدي_التطبيق
DEVELOPER_IDS=آيديك,آيدي_شريكك
DEV_GUILD_ID=آيدي_سيرفر_التجربة
```

```bash
# 3. انشر أوامر السلاش
npm run deploy

# 4. شغّل البوت
npm start
```

> **مهم:** `DEV_GUILD_ID` يجعل الأوامر تظهر فورًا في سيرفر واحد للتجربة. لنشرها في كل السيرفرات، اتركه فارغًا — لكن انتشارها قد يستغرق حتى ساعة (هذا قيد من ديسكورد).

## 3) إعداد البوت في بورتال ديسكورد

من [Discord Developer Portal](https://discord.com/developers/applications) ← تطبيقك ← **Bot**، فعّل:

- ✅ **Server Members Intent** — مطلوب للترحيب والرتب التلقائية وتتبّع النشاط
- ✅ **Message Content Intent** — مطلوب لأوامر البريفكس

بدون هذين الخيارين لن يعمل جزء كبير من البوت.

**صلاحيات البوت في السيرفر:**

| الصلاحية | لماذا |
|---|---|
| Manage Roles | الترقية، الرتب الذاتية، الرتب التلقائية |
| Ban / Kick / Moderate Members | أوامر العقوبات |
| Manage Channels | التذاكر، قفل القنوات، الوضع البطيء |
| Manage Messages | حذف الرسائل |
| Mute/Deafen/Move Members | الإدارة الصوتية |
| View Audit Log | نظام الحماية |
| Send Messages / Embed Links / Attach Files | كل الردود والسجلات |

⚠️ **ضع رتبة البوت فوق كل الرتب التي تريده يديرها.** ديسكورد يمنع أي بوت من التصرف في رتبة أعلى منه، ولا يوجد التفاف على هذا.

## 4) الإعداد الأول (5 دقائق)

اكتب `/panel` وستفتح لك لوحة التحكم المركزية:

1. **الإعدادات ← تحديد الرتب** — اختر رتبة الطاقم الأساسية
2. **السجلات** — اربط قناة لكل نوع سجل تريده
3. **تشغيل الأنظمة** — فعّل التذاكر والحماية حسب حاجتك
4. `/staff-rank add` — ابنِ السلم الإداري من الأدنى إلى الأعلى
5. `/ticket-panel` — أنشئ لوحة التذاكر في قناة الدعم

## 6) نظام الصلاحيات

| المستوى | من | كيف يُحدَّد |
|---|---|---|
| 0 — عضو | الجميع | افتراضي |
| 1 — طاقم إداري | حاملو رتبة الطاقم | تُضبط من `/panel` |
| 2 — مشرف | من يملك Ban/Kick/Moderate/ManageMessages | صلاحيات ديسكورد أو السلم الإداري |
| 3 — أدمن | من يملك Administrator | صلاحيات ديسكورد |
| 4 — مالك السيرفر | مالك السيرفر | تلقائي |
| 5 — مطور | آيديات `DEVELOPER_IDS` | من `.env` فقط |

**قواعد ثابتة لا تُخترق:**
- لا أحد يتصرف في عضو رتبته أعلى أو تساويه
- لا أحد يمس مالك السيرفر
- لا أحد يمنح رتبة أعلى من رتبته
- البوت لا يتجاوز تسلسل رتب ديسكورد، حتى لو كان الطالب مطورًا
- **كل زر وقائمة ومودال يُعيد فحص الصلاحية من الخادم عند الضغط** — إخفاء الزر ليس حماية

## 7) استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| البوت لا يرد على البريفكس | فعّل **Message Content Intent** في البورتال |
| أوامر السلاش لا تظهر | شغّل `npm run deploy`، وتأكد أن `CLIENT_ID` صحيح |
| "رتبة البوت أقل من..." | ارفع رتبة البوت فوق الرتبة المستهدفة |
| السجلات لا تصل | اربط القنوات من `/panel` ← السجلات، وتأكد أن البوت يقدر يرسل فيها |
| فشل `npm install` | ثبّت أدوات البناء (القسم 1) |
| نظام الحماية لا يعمل | يحتاج صلاحية **View Audit Log** + تفعيله من `/security toggle` |

**لتشخيص أي مشكلة:** `/dev diagnostics` يعطيك حالة كل نظام، و`/dev errors` يعرض آخر الأخطاء برقم كل خطأ.

## 9) ملاحظات مهمة

- **قاعدة البيانات:** SQLite بمعاملات ACID حقيقية. تُنشأ تلقائيًا في `data/bot.db`. خذ نسخة احتياطية منها دوريًا.
- **الأسرار:** لا تضع التوكن في الكود أبدًا ولا ترفع `.env` على Git — الملف مستثنى مسبقًا في `.gitignore`.
- **تعديل النصوص:** كل النصوص في `locales/ar.json`، عدّلها بدون لمس الكود.
- **إضافة أمر:** أنشئ ملفًا في `src/modules/<النظام>/commands/`، وسيُحمَّل تلقائيًا ويظهر في `/help` بدون أي تعديل آخر.
