# دليل الأنظمة (الإصدار 37)

كل نظام: أين يعيش، ومن أين يُدار. مرجع الأوامر الكامل مولَّد في [COMMANDS.md](COMMANDS.md).

> **خارج النطاق عمدًا**: لم يُضف ولم يُوسَّع أي نظام حماية (AutoMod، Anti-Raid، Anti-Nuke، Anti-Spam، Anti-Scam، Anti-Phishing، حماية Webhook، أوضاع الطوارئ، مراكز الأمان…). أنظمة الحماية الموجودة بقيت كما هي. التحقق هنا **وظيفي** فقط (زر + رتب + قناة + رسالة + سجل) بلا CAPTCHA.

## الحدود والأداء (1000+ سيرفر)
- كاشات محدودة الحجم بالمفتاح والمدة؛ لا ذاكرة تنمو بلا حد.
- الكتابات عالية التكرار (النشاط، الإنجازات) تُجمَّع وتُفرَّغ دوريًا في معاملة واحدة.
- الأعمال الثقيلة (خاص جماعي، استعادة، إعلانات) عبر الطابور مع تقدّم وإلغاء واستئناف.
- كل الطلبات الخارجية عبر `safeFetch` (حماية SSRF، مهلة، حد حجم، بلا إعادة توجيه لعناوين داخلية).
- حدود ديسكورد مفحوصة آليًا في `npm run check` (100 أمر سلاش، 25 خيارًا، 4000 حرف لكل أمر).
