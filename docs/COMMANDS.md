# مرجع الأوامر

> مولَّد تلقائيًا بـ `npm run docs` من سجل الأوامر — لا تعدّله يدويًا.

الإجمالي: **101** أمر • أوامر سلاش: **100/100**

كل الأوامر تعمل بالسلاش، ومعظمها بالبريفكس أيضًا (عدا المعلَّمة "سلاش فقط"). الصلاحية تُفحص في الخادم دائمًا، وقد تعدّلها قواعد `/اعداد permissions`.

## applications

### `تقديم` — `application` `تقديمات`

إنشاء أنواع التقديمات بأسئلة، ونشرها للمراجعة بأزرار قبول ورفض.

- الصلاحية: **الطاقم** • سلاش فقط
- الاستخدام: `/application create name:العصابات label:تقديم العصابات review:#المراجعة role:@عصابة`
- الأوامر الفرعية:
  - `create` — إنشاء نوع تقديم
  - `form` — ضبط أسئلة التقديم
  - `edit` — فتح محرّر التقديم التفاعلي
  - `set` — تعديل خاصية واحدة مباشرة
  - `list` — عرض أنواع التقديم
  - `panel` — نشر لوحة تصفّح التقديمات (فئات ثم أنواع) بالشكل الحديث
  - `pending` — الطلبات المعلّقة
  - `show` — عرض طلب
  - `delete` — حذف نوع تقديم
  - `schedule` — فتح/إغلاق مجدول وحدود العدد
  - `stats` — إحصاءات نموذج
  - `export` — تصدير الإجابات
